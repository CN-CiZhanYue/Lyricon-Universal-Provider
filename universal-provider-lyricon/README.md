## 模块信息

- **模块名称**：词幕通用播放器 Provider
- **模块包名**：io.github.cn_cizhanyue.lyricon.universal.provider
- **模块简介**：为词幕 Lyricon 提供通用播放器歌词源的 Provider 模块，一个模块补上状态栏歌词的最后一公里。
- **源码仓库**：https://github.com/CN-CiZhanYue/Lyricon-Universal-Provider
- **许可证**：Apache-2.0
- **支持框架**：LSPosed
- **作用域**：系统

## 说明

本模块基于 ColorOS-Live-Lyrics-Providers 的 universal-provider 适配，只向词幕推送歌词，不写入 lyricInfo，可与锁屏歌词模块共存。
